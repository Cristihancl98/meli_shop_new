Conectar una Tienda de Mercado Libre

✅ Un usuario puede conectar N cuentas de MeLi. Cada cuenta es independiente y tiene sus propios productos, órdenes y estadísticas.

Prerequisitos

  • Aplicación Laravel funcionando localmente (php artisan serve)
  • Cuenta de Mercado Libre Colombia activa como vendedor
  • Acceso al portal de desarrolladores de MeLi
  • Variables de entorno configuradas en .env
1️⃣

Registrar la App en el Portal de Desarrolladores

ℹ️ Debes crear una aplicación en el portal de desarrolladores de MeLi para obtener las credenciales OAuth2. Este paso se hace una sola vez por proyecto.
  1. Ingresar al portal de desarrolladores
    Ir a developers.mercadolibre.com.co e iniciar sesión con la cuenta de MeLi Colombia que usarás como cuenta principal.
  2. Crear una nueva aplicación
    Ir a Mis Aplicaciones → Crear Aplicación. Completar nombre, descripción corta y seleccionar Colombia (MCO) como país.
  3. Configurar el Redirect URI
    En la sección URLs de redireccionamiento, agregar exactamente la siguiente URL: 
    http://localhost:8000/meli/callback
    Para producción, cambiar por: https://tudominio.com/meli/callback
  4. Activar los Scopes requeridos
    En la sección Permisos, habilitar los siguientes scopes:
    read write offline_access

    El scope offline_access es necesario para obtener el refresh_token y mantener la sesión activa.

  5. Copiar Client ID y Client Secret
    Después de guardar, la plataforma muestra el APP_ID (Client ID) y el Secret Key (Client Secret). Guardar estos valores.
2️⃣

Configurar Variables de Entorno

Variables MeLi en .env

# MercadoLibre Colombia (MCO)
MELI_CLIENT_ID=tu_app_id_aqui
MELI_CLIENT_SECRET=tu_secret_key_aqui
MELI_REDIRECT_URI=http://localhost:8000/meli/callback

Configuración en config/services.php

El archivo ya tiene el bloque configurado para leer las variables del .env:

'mercadolibre' => [
    'client_id'    => env('MELI_CLIENT_ID'),
    'client_secret'=> env('MELI_CLIENT_SECRET'),
    'redirect_uri' => env('MELI_REDIRECT_URI'),
    'auth_url'     => 'https://auth.mercadolibre.com.co/authorization',
    'token_url'    => 'https://api.mercadolibre.com/oauth/token',
    'api_base'     => 'https://api.mercadolibre.com',
    'country_code' => 'MCO',
],
⚠️ Después de modificar el .env, limpiar el caché: php artisan config:clear

La conexión usa OAuth2 Authorization Code Grant. El flujo completo tiene 5 pasos que ocurren automáticamente:

→

→
Redirect a
mercadolibre.com.co
/authorization
→
Usuario autoriza

¿Qué hace GET /meli/connect?

Construye la URL de autorización con los parámetros requeridos y redirige al usuario:

https://auth.mercadolibre.com.co/authorization
  ?response_type=code
  &client_id={MELI_CLIENT_ID}
  &redirect_uri={MELI_REDIRECT_URI}
  &scope=read+write+offline_access
ℹ️ Este endpoint requiere autenticación JWT — el usuario debe estar logueado en el panel antes de conectar su tienda MeLi.

¿Qué hace GET /meli/callback?

MeLi redirige aquí con un code temporal. El sistema:

  1. Intercambia el code por access_token y refresh_token
  2. Llama GET /users/me para obtener el meli_user_id y nickname de la cuenta
  3. Guarda o actualiza el registro en mercadolibre_accounts
  4. Redirige al usuario al dashboard con mensaje de éxito

Datos guardados en mercadolibre_accounts

CampoValor
user_idID del usuario del panel (FK)
meli_user_idID del vendedor en MeLi (ej: 123456789)
nicknameNickname en MeLi (ej: TIENDA_EJEMPLO_CO)
access_tokenToken de acceso (válido 6 horas)
refresh_tokenToken de renovación (larga duración)
expires_atTimestamp de expiración del access_token
is_activetrue — la cuenta queda activa automáticamente
4️⃣

Conectar una Tienda desde la Interfaz

  1. Iniciar sesión en el panel
    Abrir http://localhost:8000 e ingresar con las credenciales de administrador: 
    Email:    admin@marketplace.com
Password: password
  2. Ir a "Mis Tiendas"
    En el menú lateral izquierdo, buscar la sección Tiendas MeLi y hacer clic en Mis Tiendas.
  3. Hacer clic en "Conectar con MeLi"
    El botón genera la URL OAuth y redirige automáticamente al portal de autorización de Mercado Libre Colombia.
  4. Autorizar la aplicación en MeLi
    En la pantalla de MeLi, revisar los permisos solicitados (lectura, escritura y acceso offline) y hacer clic en Permitir.
  5. Confirmación y redirección
    El sistema redirige de vuelta al panel. La tienda aparece como Activa en la lista de tiendas conectadas, lista para sincronizar.
✅ Una vez conectada, la tienda comienza a sincronizarse automáticamente en el próximo ciclo del scheduler (máximo 30 minutos para productos, 10 minutos para órdenes).
5️⃣

Gestionar Múltiples Tiendas

🏪 El sistema soporta N cuentas MeLi por usuario. Cada cuenta tiene sus propios productos, órdenes, clientes y estadísticas completamente separados.

Ejemplo: 3 tiendas conectadas

T1
TIENDA_PRINCIPAL
meli_user_id: 123456789
Activa · 245 productos · 89 órdenes
T2
TIENDA_ELECTRONICA
meli_user_id: 987654321
Activa · 78 productos · 34 órdenes
T3
TIENDA_ROPA
meli_user_id: 456789123
Inactiva · Token expirado

Cómo conectar una segunda tienda

Repetir exactamente el mismo flujo OAuth2. El sistema detecta si la cuenta ya existe por meli_user_id:

  • Si meli_user_id es nuevo → crea un nuevo registro en mercadolibre_accounts
  • Si meli_user_id ya existe → actualiza los tokens (reconexión)
⚠️ Para conectar una segunda cuenta diferente, usar una sesión de navegador distinta o modo incógnito en la pantalla de autorización de MeLi, para que no tome la sesión activa.

Activar / Desactivar una tienda

Cambiar el campo is_active en la tabla mercadolibre_accounts:

-- Desactivar tienda
UPDATE mercadolibre_accounts SET is_active = 0 WHERE id = 3;

-- Activar tienda
UPDATE mercadolibre_accounts SET is_active = 1 WHERE id = 3;

Las tiendas inactivas se excluyen automáticamente de los Jobs de sincronización.

Aislamiento de datos entre tiendas

Todos los modelos tienen la columna mercadolibre_account_id que garantiza el aislamiento:

customersmercadolibre_account_idClientes separados por tienda
sales_statisticsmercadolibre_account_idEstadísticas por tienda

Solución de Problemas

Error: "redirect_uri no coincide"

La URL configurada en el portal de MeLi developers no coincide exactamente con MELI_REDIRECT_URI en el .env. Verificar que sean idénticas, incluyendo el protocolo (http vs https) y la barra final.

Error 401 al llamar la API de MeLi

El access_token expiró y el refresh falló. Revisar el sync_logs con status = 'error' y reconectar la cuenta desde la UI.

-- Ver últimos errores de sync
SELECT * FROM sync_logs
WHERE status = 'error'
ORDER BY created_at DESC
LIMIT 10;

La tienda no aparece después del callback

  • Verificar que el Queue Worker esté corriendo: php artisan queue:listen
  • Revisar el log de Laravel: storage/logs/laravel.log
  • Confirmar que MELI_CLIENT_ID y MELI_CLIENT_SECRET son correctos

Reiniciar la conexión de una tienda

Si necesitas reconectar una tienda existente (tokens inválidos), simplemente repetir el flujo OAuth2. El sistema actualizará los tokens automáticamente por meli_user_id.

-- Verificar estado de las cuentas
SELECT id, meli_user_id, nickname, is_active, expires_at
FROM mercadolibre_accounts
WHERE user_id = 1;
