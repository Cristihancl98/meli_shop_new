Campos del formulario

title requerido
string, max:255
Título del anuncio en MeLi. Visible para compradores.
price requerido
decimal, min:0
Precio en pesos colombianos (COP). Ejemplo: 89900.00
stock requerido
integer, min:0
Unidades disponibles. 0 = sin stock (pausa automática en MeLi).
condition requerido
enum: new / used
Estado del producto. Obligatorio para MeLi.
listing_type_id requerido
enum
Tipo de publicación: free, bronze, gold_special, etc.
category_id opcional
integer, FK
Categoría MeLi local. Se mapea al meli_category_id para la publicación.
description opcional
string
Descripción detallada. Soporta texto largo. Se envía a MeLi.
image opcional
file: jpg/jpeg/png/webp, max 5MB
Imagen principal. Se sube a S3 y luego a MeLi via /pictures/items/upload.

Creación via API REST

Enviar como multipart/form-data para incluir la imagen:

POST /api/products
Authorization: Bearer {token}
Content-Type: multipart/form-data

title=Camiseta Polo Azul
price=89900
stock=50
condition=new
listing_type_id=gold_special
description=Camiseta de algodón 100%...
image=@/ruta/imagen.jpg

Respuesta exitosa

{
  "success": true,
  "data": {
    "id": 42,
    "meli_item_id": "MCO123456789",
    "title": "Camiseta Polo Azul",
    "price": "89900.00",
    "stock": 50,
    "status": "active",
    "thumbnail": "https://s3.amazonaws.com/tu-bucket/products/abc123.jpg",
    "condition": "new",
    "listing_type_id": "gold_special",
    "last_sync": "2026-06-16T10:30:00Z"
  },
  "message": "Producto creado y publicado en MercadoLibre exitosamente"
}
ℹ️ Si la subida de imagen a MeLi falla (error de red), el producto se guarda igualmente en la base de datos con la URL de S3. Se puede forzar una sincronización posterior.

Campos editables

Todos los campos del formulario de creación son editables. En la API, usar PUT con solo los campos a modificar (todos son sometimes):

PUT /api/products/42
Authorization: Bearer {token}
Content-Type: application/json

{
  "price": 79900,
  "stock": 35
}

Cambiar precio desde la UI

  1. Ir a la lista de productos
    Navegar a /products y buscar el producto a editar.
  2. Abrir el formulario de edición
    Hacer clic en el botón Editar en la tarjeta del producto o desde la página de detalle.
  3. Modificar el precio y guardar
    Cambiar el campo Precio (COP), hacer clic en Guardar Cambios. El precio se actualiza en MeLi inmediatamente.

Eliminar un Producto

🚨 La eliminación usa soft delete. El producto se marca como cerrado en MeLi y se oculta del panel, pero los datos históricos (órdenes, estadísticas) se conservan.

¿Qué ocurre al eliminar?

  1. Se llama a la API de MeLi para cambiar el status del ítem a closed
  2. Se establece deleted_at = now() en la tabla products
  3. El producto desaparece de todos los listados del panel
  4. Los order_items que referencian el producto conservan el product_id

Eliminar desde la UI

En la vista de edición (/products/{id}/edit), hacer clic en el botón rojo Eliminar Producto. El sistema pide confirmación antes de proceder.

Eliminar via API

DELETE /api/products/42
Authorization: Bearer {token}

// Respuesta
{
  "success": true,
  "data": null,
  "message": "Producto eliminado exitosamente"
}

Recuperar un producto eliminado (soft delete)

Los registros con deleted_at no nulo se pueden restaurar directamente en base de datos:

-- Restaurar producto con ID 42
UPDATE products SET deleted_at = NULL WHERE id = 42;
ℹ️ Después de restaurar, hay que sincronizar manualmente el producto para reactivarlo en MeLi: POST /api/products/42/sync

Estados del Producto

Posibles estados y su significado

EstadoEn BDEn MeLiVisible para compradores
active status = 'active' Publicado y activo Sí
paused status = 'paused' Pausado por el vendedor o por stock = 0 No
closed status = 'closed' Cerrado / finalizado No

Transiciones de estado

active → stock llega a 0 → paused (automático en MeLi)
paused → stock > 0 + sync → active
active / paused → Eliminar desde panel → closed

Referencia API REST — Productos

MétodoEndpointDescripciónRol mínimo
GET /api/products Listado paginado con filtros Operador
GET /api/products/{id} Detalle del producto Operador
POST /api/products Crear producto + publicar en MeLi Admin
PUT /api/products/{id} Editar producto + actualizar en MeLi Admin
DELETE /api/products/{id} Cerrar en MeLi + soft delete Admin
POST /api/products/{id}/sync Forzar sincronización desde MeLi Admin

Headers requeridos en todas las peticiones

Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
Accept: application/json
Content-Type: application/json   # (o multipart/form-data para subir imagen)

Estructura de respuesta estándar

{
  "success": true | false,
  "data": { ... },          // Objeto o array de resultados
  "message": "...",         // Mensaje descriptivo en español
  "errors": { ... }         // Solo presente cuando success=false
}
