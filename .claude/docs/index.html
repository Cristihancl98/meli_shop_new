Resumen del Proyecto

✓ Completado · 12/12 fases

¿Qué es este sistema?

Panel administrativo web para gestionar publicaciones, ventas, clientes y métricas de Mercado Libre Colombia (MCO) desde una sola interfaz. Permite sincronizar datos automáticamente, exportar reportes y gestionar múltiples cuentas de MeLi por usuario.

Progreso general: 100% — Proyecto completo (12/12 fases)

🎯 Objetivo

Reemplazar la gestión manual en MeLi con un panel centralizado que sincroniza datos automáticamente cada 10–60 minutos vía Jobs y Queues.

🌎 País

Mercado Libre Colombia MCO. Moneda COP. Auth URL: auth.mercadolibre.com.co. API: api.mercadolibre.com

👥 Roles

Admin: Acceso total (CRUD, exportar, sincronizar).
Operador: Solo lectura de productos, ventas y clientes.

🔑 Credenciales Dev

Admin: admin@marketplace.com / password
Operador: operador@marketplace.com / password

Fase 11 — Jobs / Scheduler

✓ Completada

Jobs implementados

  • app/Jobs/SyncProductsJob.phpPagina resultados MeLi (limit 50), crea/actualiza productos, despacha ProductSynced. Manejo per-ítem para no abortar batch.
  • app/Jobs/SyncOrdersJob.phpFiltra órdenes desde las últimas 24h (configurable). Usa DB::transaction por orden. Crea Customer si no existe. Sincroniza OrderItems con product_id resuelto.
  • app/Jobs/SyncCustomersJob.phpItera clientes existentes con meli_customer_id via chunkById(50). Refresca name, email, phone, nickname. Despacha CustomerSynced.
  • app/Jobs/CalculateStatisticsJob.phpRecalcula sales_statistics (GROUP BY DATE) y product_statistics (JOIN order_items) para todas las órdenes paid de la cuenta.

Listeners (ShouldQueue)

  • UpdateProductStatisticsProductSynced → recalcula quantity_sold + total_revenue desde order_items JOIN orders.
  • UpdateSalesStatisticsOrderSynced → actualiza sales_statistics del día + product_statistics de cada item.
  • LogCustomerActivityCustomerSynced → Log::channel('stack').
  • LogTokenRefreshMeliTokenRefreshed → Log::info con account_id y expires_at.
  • NotifyAdminOfFailureSyncFailed → Log::error (extensible a email/Slack).

Artisan Commands

php artisan sync:products [--account=ID]       # Encola SyncProductsJob por cuenta
php artisan sync:orders [--account=ID] [--from=ISO8601]  # Encola SyncOrdersJob
php artisan sync:customers [--account=ID]      # Encola SyncCustomersJob
php artisan calculate:statistics [--account=ID] # Encola CalculateStatisticsJob
